### Key Design Decisions
- **Defensive imports** — all backend modules wrapped in try/except with `*_AVAILABLE` flags
  - Allows UI to render even when Linguini's modules aren't present
  - Enables parallel development
- **SDL framebuffer pattern** — reused from labs (`os.environ.setdefault`)
  - Auto-targets `/dev/fb0` on headless Pi
  - Uses normal windowing on desktop
- **6 FPS preview loop** — `pygame.time.Clock.tick(6)`
  - Power efficiency on Pi
  - Balances smooth preview with battery/thermals
- **Start/Stop button swap** — only one action button visible at a time
  - Prevents accidental double-taps on touchscreen
- **Session resume on init** — checks `storage.find_interrupted_session()`
  - Resumes interrupted session on next Start press
