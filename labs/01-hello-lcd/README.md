# Lab 01 — Hello LCD

A simple "Hello World" for the Waveshare 3.5" RPi LCD (A).

## What It Does

- Fills the screen with a dark-blue background
- Draws a rounded rectangle (red) and a circle (green)
- Displays "Hello, LCD!" in large text
- Shows display specs and pygame version

## Prerequisites

- Waveshare LCD driver installed (`sudo ./LCD35-show`)
- Python 3 with pygame: `pip install pygame`

## How to Run

```bash
python hello_lcd.py
```

## What to Expect

The LCD shows colored shapes and text. Press **ESC** or **Ctrl+C** to exit.
